## Composite likelihood and bootstrap

The pipeline's `fit_cl` uses `neglogcl` from `functions.R`. It produces estimates different from the report's Table 4, including a correlation estimate close to 1. Successful optimizer termination alone does not validate that fit.

The report's stationary AR(1) model uses innovation variance `sigma2` and pairwise covariance `sigma2 / (1 - gamma^2) * matrix(c(1, gamma, gamma, 1), 2)`. The formula implemented in `neglogcl` does not match that parameterization. For that covariance, the determinant is `sigma2^2 / (1 - gamma^2)` and the quadratic contribution is `quad / sigma2`. The supplied function instead uses a product in the determinant and multiplies the quadratic contribution by `(1 - gamma^2)`. The original code is retained for review rather than silently changing the analysis.

`compositeLscript.R` uses a separate bivariate-normal implementation. It references missing `CAcropdata.txt` and an existing `veg.1` object. Its optimizer does not explicitly constrain the variance/correlation domain, and its bootstrap accepts any non-error fit without checking the convergence code. Thus, neither the report's composite estimates nor its 1,000-replicate intervals are claimed as reproduced here.

`others.R` also expects `veg.1`, has duplicate `zt` arguments in its bootstrap optimizer call, and calls `set.seed(NULL)`. The extensionless combined script repeats several of these exploratory sections and is not a standalone entry point.

## Interpretation and plotting details

- `optim()` returns the minimized **negative** log likelihood in `$value`; the original result commands and report label positive objective values as log likelihoods. For the reproduced full AR(1) fits, log likelihoods are approximately -48.48149 (vegetables) and -0.4820994 (fruit).
- AR(1) innovation variance is not the same quantity as stationary error variance, which is `sigma2 / (1 - phi^2)`. Comparisons with independent-error residual variance need to respect that distinction.
- `results.call.R` requires session objects such as `vegnew`; its base graphics calls do not create grobs for `grid.arrange()`. It also uses hard-coded AR(1) coefficients for innovation plots. The added runner generates plots directly from current estimates instead.
- The original ACF figure leaves the first error unadjusted. The runner scales it by `sqrt(1 - phi^2)`, consistent with stationary initialization. The new ACF plot may therefore differ slightly from the original supplied PNG.
- The original pipeline reads CSVs inside targets rather than using tracked file targets. After replacing those inputs, invalidate `veg.data` and `fruit.data` before rebuilding.
- No bootstrap confidence intervals or combined Gompertz-with-AR(1) model are generated by the added runner. The latter is proposed as future work in the report.
